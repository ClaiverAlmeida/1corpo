# 1Corpo — Site

Uma plataforma. Cada igreja, o seu espaço.

Site institucional do 1Corpo, em um único arquivo (`index.html`), sem dependências nem build.

## Publicar no GitHub Pages

1. Envie os arquivos desta pasta para a branch `main` do repositório.
2. No GitHub: **Settings › Pages › Build and deployment › Source: Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O site fica em `https://claiveralmeida.github.io/1corpo/`.

Somos muitos, e um só corpo.
